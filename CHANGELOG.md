# Changelog
## 0.3.0 — 2026-11
- Yarn Classic (`yarn.lock` v1) support with automatic format detection; Yarn Berry and pnpm lockfiles are rejected with an explicit message.
- `registry.yarnpkg.com` added to the default trusted hosts.
- Reported tool version now comes from the package, not a hard-coded string (it previously said 0.1.0).
- 13 new tests (30 total), including a lockfile generated by Yarn 1.

## 0.2.0 — 2026-10
Added `--format sarif`, so findings can go straight into GitHub code scanning or another SARIF viewer.

## 0.1.0 — 2026-10
Initial release. See the README for features and limits.
